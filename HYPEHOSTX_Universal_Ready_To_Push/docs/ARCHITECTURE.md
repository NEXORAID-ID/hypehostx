# Architecture
Static HTML is generated for two locales with relative project paths. The language switch navigates to a complete localized counterpart; static navigation remains available when JS is disabled. `data.json` is embedded as a local script at build time. Baseline JS uses ES5-style syntax; optional browser APIs are feature detected. CSS avoids mandatory grid, remote fonts and CDN dependencies. The console hint is based only on an explicit PlayStation user-agent token, not proof of hardware or firmware. Exact firmware is manually entered; PS3 type is required for a positive record match. Unknowns remain unknown. The service worker is opt-in, scoped to the project, caches only original generated files, checks SHA-256 at install, uses the installed revision for coherent offline reads, and removes older project caches after successful activation. Browser runtime validation remains pending in this environment. Clear unregisters the project-scoped worker and removes matching cache keys; reload/close controlled tabs afterward. A generated asset list and checksums are reproducible, but do not serve as signed release attestation.

Original data and interface are public reference information. No third-party executing code, payload or firmware is part of the build. The only persistent user data is local preferences and an optional firmware choice; diagnostics are local and omit raw user agent, IP and account data. A direct 404 page includes a canonical home link to recover from arbitrary nested missing paths; legacy CSS/JS on those paths may not load.

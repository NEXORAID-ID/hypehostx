# Local operations and rollback

Static preview binds only to loopback. Publish only `dist/web` after an approved release; never publish the repository root. The proposed URL remains unverified. There is no automatic deployment workflow. CI is read-only and its cloud execution has not been observed.

Optional database container: copy `.env.example` to `.env`, replace the placeholder password with a private local-only value, and use that same value in `DATABASE_URL` (URL-encode any reserved characters). Then run `docker compose -f infra/compose.yml up -d`, `npm run build:backend`, and `npm run start:backend`. The start command loads `.env` through Node's built-in env-file support. Docker is unavailable in this environment, so this configuration has not been run. PostgreSQL 17.6-alpine is a pinned version tag, not an immutable digest; review/pin a digest before production. The application and migration process currently share a local development role; split migration and runtime grants before production. `ALLOWED_ORIGINS` must contain the exact comma-separated browser origins; do not use a wildcard. Registration/reset return 503 until an approved mail transport is configured; `npm run dev:network` instead uses PGlite and a private local mail sink.

Backup: a real PGlite data archive was restored into a separate engine in the security test. This proves the local engine workflow only. Production `pg_dump`/restore, backup retention and multi-client transaction races still need a Docker/server drill. Never roll a schema back by dropping user data. Preserve a backup, deploy an application compatible with current schema, and use a forward corrective migration.

Web rollback: retain each reviewed archive and its checksum. Restore the previous allowlisted directory and confirm all manifest hashes before serving it. Cache workers are versioned; offline users may retain prior caches and cannot be forcibly revoked. Close all tabs/reopen and use browser-specific cache recovery as needed. No claim is made that a public rollback has run.

Secrets: `.env`, local mail, app saves, database files, tokens and private rights evidence are not release inputs. Development bearer tokens live in memory. Scope file transfer to a private app directory, use a five-minute maximum session, stop it when finished, and do not bind beyond loopback. Transfer is a host SDK tool, not a console network server.

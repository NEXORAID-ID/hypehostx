HYPEPAYLOAD / LOCAL UPSTREAM

UMTX2 + etaHEN

Host UMTX2 dengan 29 offset firmware persis (1.00–5.50). etaHEN 2.4B mempertahankan pasangan upstream; 2.5B menjadi opsi menu manual terpisah. Label model bukan jaminan dukungan.

Buka host upstream lokal

Instalasi / aktivasi native: belum diuji pada perangkat asli.

Commit sumber & inventaris SHA-256

PS5 Relapse / ELF loader

Pilih firmware pada daftar di atas untuk menentukan host. Relapse memiliki 33 offset versi 7.00?13.60. Ini menjalankan loader; etaHEN memerlukan pengiriman payload terpisah dari komputer. Keberadaan offset tidak membuktikan kompatibilitas etaHEN.

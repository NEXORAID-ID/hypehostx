# Contributing

Read root AGENTS.md and master v5.2. Preserve exact ticket/QA IDs and record real commands, exits and evidence. Keep unrelated work. Tests and mocks belong outside stable artifacts. Never upgrade desktop results to PS4 compatibility, rename vendor binaries, or infer licenses from public visibility.

Run local validation/build/tests before proposing changes. Use semantic commits if committing; no force pushes. Publication and original-code license are owner decisions. Private tokens, mail, personal records, grants and build caches must remain ignored.
